Optional fields under More (23 Oct) contradict notes unfolded (29 Oct). Start here moved to Home and back. **Fix:** before building, grep `DECISIONS.md` for the surface. If the request reverses an entry, say so, ask once, and mark the old entry superseded.

The 1 Nov session ran out of context, and the 31 Oct `/clear` lost agent work (you asked "check the completed tasks"). **Fix:** the last message of every session lists each request as done (with hash) or open (with the reason).

(Resolved 11 Nov: `BRIEF-changes.md` is now a record of what was built, and `AGENTS.md` invariant 12 says requests are done in the session.) `AGENTS.md` still sends sessions to that brief. **Fix:** `DECISIONS.md` and your message outrank the brief, and no session writes "proposed brief edits" instead of working.

## Three structural problems

1. **Every change fans out.** One UI tweak touches `sheets.tsx` (905 long lines), CSS, English and French strings, 34 manual pages, screenshots, `DECISIONS.md`, the relay (a redeploy) and often a migration. Sessions run out of context (the 400k-token session). **Fix:** one change to the manual per session at most. Screenshots and French in a batch (French now goes in with each change, `AGENTS.md` invariant 5). Split `sheets.tsx` by sheet (done 11 Nov: `sheetBase`, `timerSheets`, `taskSheet`, `moveSheets`).
2. **No oracle for what you see.** iOS top, wrapping at 320 px, push and the planning message can only be judged on your phone. Tests spoof them, and the phone tests from S1 to S9 are still owed. **Fix:** a short "owed on device" list in the final message of every session, and layout bugs get a 320/375/430 test that measures the symptom.
3. **Rules duplicated by surface.** Drop had three implementations (one now: **441a595**), Start here two (one now, on Today alone: **3ce4c7c**), and calendar text four (`calItems`, `ics`, `feedText`, `calView`: now layered, `calItems` decides the words, `ics` only formats, `feedText` is shared with the connector, `calView` reads `calItems` and `ics`, no second copy of a rule: **4172ef7**, **2783698**). The weekly review's "Drop it" buttons (`flows/review.tsx`) still drop on one tap and are not `DropButton`: left as they are, because merging would add a second tap to a list the owner works through quickly. `DECISIONS.md` has 461 entries that contradict each other (298, 332, 339). **Fix:** one component or function per interaction; the next session that touches a duplicate merges it.
