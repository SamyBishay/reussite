# La mémoire

La mémoire garde de courtes notes sur les personnes, les lieux et les sujets de votre vie. Une ligne par fait, avec vos mots. Ouvrez-la depuis le menu de l’accueil.

![La mémoire : des notes groupées par type](shot:memory)

## Ce qu’est une note

Une note a un nom, un type (**Profil**, **Personne**, **Lieu**, **Domaine** ou **Sujet**), d’autres noms facultatifs (« aussi appelé »), et des lignes. Par exemple, une note appelée « Alex » pourrait dire « Joue du violoncelle dans la chorale » et « Préfère un message à un appel ».

Touchez **Nouvelle note** pour en ajouter une. Ouvrez une note pour ajouter une ligne, en modifier une, ou ajouter un autre nom.

## À quoi elle sert

Si vous utilisez une IA, les notes qui correspondent à votre demande peuvent partir avec elle, pour que vous n’ayez pas à tout réexpliquer. « Montrer ce qui est envoyé » les liste. Vous choisissez la quantité de mémoire qu’une demande peut emporter dans Réglages → IA.

Une IA peut suggérer une nouvelle note ou une correction. Vous la cochez d’abord, comme tout autre changement.

## Les notes privées

Marquez une note **Privée : jamais envoyée à une IA**. Aucune IA ne la voit alors : ni celle de l’appli, ni Claude par le connecteur. Elle voyage quand même avec votre synchronisation, chiffrée comme le reste.

## Oublier

**Oublier** supprime pour de vrai. Les mots disparaissent, y compris de votre historique et de votre copie synchronisée. On ne peut pas revenir en arrière.

## Importer et exporter

- **Importer** lit les fichiers de mémoire de Claude Code, un fichier de la mémoire de claude.ai, ou du texte que vous collez. Rien n’est remplacé : seules les lignes que vous n’avez pas encore sont ajoutées. Vous voyez un résumé avant que quoi que ce soit soit écrit.
- **Exporter** produit un fichier Markdown avec un bloc par note, à donner à n’importe quelle IA. Les notes privées restent dehors, sauf si vous cochez la case.
